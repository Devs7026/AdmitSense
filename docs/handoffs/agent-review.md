Implemented:
- Built initial waiting-period review engine in `src/admitsense/agent/review.py` (`WaitingPeriodReviewer` and `run_waiting_period_review`):
  - Conforms to `ReviewRunner` protocol in `docs/CONTRACTS.md`.
  - Accepts saved case (`CaseDetails`) and retrieval service (`EvidenceRetrieval` / `EvidenceRetrievalService`).
  - Evaluates case facts with provenance (`FactSource`); preserves unknown facts as `None`.
  - Searches policy documents and extracts relevant condition-specific waiting period clauses from actual page texts.
  - Verifies evidence citations against physical 1-based page text (e.g. Section 4.2(b) on physical page 14).
  - Evaluates continuous coverage history from policy schedules and case facts.
  - Core Milestone M3 Acceptance Scenario:
    - 24-month condition (degenerative joint disorders / total knee replacement under Section 4.2(b)) vs 18-month policy history:
    - Produces a cited `unresolved` finding clearly explaining the 6-month shortfall.
    - Cites authentic passages from policy wording and schedule.
    - Emits actionable next action and `MissingEvidenceItem` requesting continuous coverage / portability proof.
    - Emits clarification questions for the caregiver to ask the insurer or TPA.
    - Does NOT invent a dummy waiver document or claim overall policy coverage or insurer approval.
  - Invariant compliance:
    - Authorisation status strictly defaults to `"not verified"`.
    - Tool execution budget strictly capped at 8 calls.
    - Pure Pydantic output: returns `ReviewPacket` snapshot without side-effect writes to storage.
  - Real-time telemetry:
    - Implemented `ToolActivityEvent` schema conforming to `CONTRACTS.md` 3.3.
    - Optional `event_callback` streams caregiver-friendly tool activity events.
  - Tested against actual extracted synthetic PDFs generated by Owner A's synthetic generator.

Callable Interface for Owner A (M3-A / M3-I):
```python
from admitsense.agent import WaitingPeriodReviewer, run_waiting_period_review, ToolActivityEvent
from admitsense.schemas import CaseDetails, ReviewPacket

# Option 1: Convenience functional entry point
packet: ReviewPacket = run_waiting_period_review(
    case=case,                       # CaseDetails from CaseRepository
    retrieval=retrieval_service,     # EvidenceRetrievalService(db=db)
    tool_budget=8,                   # Optional (default: 8, max: 8)
    event_callback=on_tool_event,    # Optional: Callable[[ToolActivityEvent], None]
)

# Option 2: Class-based entry point
reviewer = WaitingPeriodReviewer(default_tool_budget=8)
packet: ReviewPacket = reviewer.run_review(
    case=case,
    retrieval=retrieval_service,
    event_callback=on_tool_event,
)
```

Error Behaviour:
- Missing procedure: If `case.procedure` is missing and cannot be found in documents, returns `ReviewPacket` with `status="incomplete"`, `stopped_reason="missing_information"`, and checklist item requesting procedure name.
- Zero documents: If case has no uploaded documents, returns `ReviewPacket` with `status="incomplete"`, `stopped_reason="missing_information"`, and checklist item requesting policy documents.
- Tool budget exhausted: If tool calls reach the budget (8 calls), terminates tool calls gracefully and returns partial results with `stopped_reason="tool_limit_reached"`.
- Unreadable documents: Flags unreadable documents as `status="uncertain"` in `DocumentApplicability` and notes in limitations that unreadable pages never imply absence of policy conditions.
